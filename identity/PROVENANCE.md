# Provenance

## First-party implementation

This foundation was designed and implemented for Ego Hygiene in 2026. The CLI,
contracts, profiles, and Empathy consumer specification are first-party work.

## Standards and platform references

The target catalog was informed by documentation from:

- GitHub repository social-preview documentation;
- MDN Web App Manifest and installable-PWA documentation;
- Apple Safari Web Clip documentation;
- web.dev maskable-icon safe-zone guidance;
- the Design Tokens Community Group specification.

These sources define requirements and interoperability constraints. No
third-party implementation code or artwork is incorporated.

Profile files record their relevant primary references and verification date.
