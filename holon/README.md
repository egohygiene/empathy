# Holon

`holon/` incubates composable repository packs and profiles inside Empathy.
Packs may contain a runnable reference template while their ownership,
interfaces, and extraction shape mature through real consumers.

Current packs:

- [`packs/react-vite`](packs/react-vite/README.md) — comprehensive React and
  Vite repository baseline.
- [`packs/readme`](packs/readme/README.md) — evidence-first project and
  profile README authoring system.
