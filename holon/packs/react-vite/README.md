# React + Vite pack

This pack combines the staged `website`, `store`, and reusable `universal`
material into one comprehensive baseline. The materialized workspace lives in
[`template/`](template/README.md).

## Ownership

- Holon owns template composition, configuration contracts, profiles, and
  promotion records.
- Product repositories own content, identity, provider credentials, and
  deployment decisions.
- Reusable implementation can be extracted only after the Empathy integration
  proves its package boundary.

## Incubation status

- Website skeleton: promoted as the broad workspace foundation.
- Store: promoted as an optional commerce profile; duplicate root scaffolding
  was dispositioned after audit.
- Universal: auth/runtime patterns promoted; maps, Kepler, and cloud-specific
  code remains staged for a later profile decision.
- Vite corpus: synthesized into a shared configuration factory; historical
  corpus remains staged until feature parity is reviewed in a later pass.
