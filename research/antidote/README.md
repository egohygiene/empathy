# Antidote migration history

Antidote graduated from Empathy into its standalone canonical repository:

<https://github.com/egohygiene/antidote>

The standalone foundation is reviewed in
[`egohygiene/antidote#1`](https://github.com/egohygiene/antidote/pull/1).

This directory intentionally contains no writable manuscript, bibliography,
research notes, data, figures, or local publication templates. Antidote owns
those artifacts; Beacon owns the versioned `research-paper` profile. Empathy is
neither a runtime dependency nor a second canonical research home.
